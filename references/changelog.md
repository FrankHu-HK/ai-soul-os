## v1.0.0 (2026-08-07) Initial Release

**New capabilities**:
- All nine soul modules covered: Identity, Personality, Core Principles, Boundaries, 5-Step Working Method, Continuity, Memory System, Decision System, Expert Router, Mission.
- Core deliverable: complete deployable SOUL.md soul framework template (`references/soul-template.md`).
- Cross-platform deployment guide: Windows/macOS/Linux + major agent framework path references (`references/deployment-guide.md`).
- Usage manual & FAQ: how to live with the deployed AI, how to iterate (`references/faq.md`).
- Error handling & reliability guarantees: insufficient-info questioning protocol, long/contradictory input fallbacks, honesty boundary statement.
- Security boundaries: anti-jailbreak/anti-injection statement, zero external links, zero data collection, fully offline self-contained.

**Structure design**:
- Main document = navigation + quick card + decision tree only (progressive disclosure); density lives in 10 references.
- First-response minimalism: 3-line overview + at most 3 key questions.

**Compatibility**:
- Plain-text output, adapts to any agent framework supporting custom system prompts/SOUL.md.
- OS-agnostic (Windows/macOS/Linux).
