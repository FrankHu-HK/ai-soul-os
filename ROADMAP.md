# Roadmap

Planned enhancements for the AI Soul Operating System.

## v1.1 (next)

- [ ] **Customization presets**: one-click soul presets (J.A.R.V.I.S / Coach / Strategist / Analyst / Companion)
- [ ] **Diagnosis report template**: a reusable five-dimension diagnosis checklist as a standalone reference
- [ ] **More expert modes**: negotiation, finance/investment, education, writing
- [ ] **Soul A/B testing guide**: how to compare two soul configs on the same model

## v1.2

- [ ] **Multi-model compatibility notes**: known behavioral differences across major models (Claude/GPT/DeepSeek/Llama) when deploying the same soul
- [ ] **Context-budget guidance**: minimal vs. full soul variants with token estimates
- [ ] **Community module registry**: user-contributed soul modules (with attribution)

## v2.0 (longer term)

- [ ] **Soul builder web tool**: form-driven soul generation (offline single-file HTML, following the org-efficiency-pro pattern)
- [ ] **Benchmark suite**: standard evaluation prompts to measure a deployed soul's fidelity across dimensions
- [ ] **Multi-language support**: zh/en parity maintained; add Japanese/Korean/Spanish community translations

## How to influence the roadmap

Open an issue with your use case. The most requested, most concrete scenarios get prioritized. See [CONTRIBUTING.md](CONTRIBUTING.md).
